# Runix Website

Official website of Runix — AI infrastructure for modern teams.

Static site (plain HTML/CSS, no build step) served via GitHub Pages.

- `index.html` — home
- `plans.html` — pricing, the four monthly plans and billing terms (`/pricing` 301s here)
- `about.html` — company and contact
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `assets/` — stylesheet and favicon
