What Unix got right, rebuilt for AI

Unix has lasted more than fifty years on a few ideas: everything is a file, small tools joined by pipes, one interface every program calls, and programs that change without touching what runs beneath them. Enterprise AI has none of that yet. Every team wires up its own storage, data scripts, model endpoints and keys. Runix Lab rebuilds those ideas as five layers.

  1. everything is a file

    Runix FS Layer 01 · Infrastructure

    Datasets, checkpoints and model weights read through one POSIX path, cached in front of the object storage you already run.

  2. small tools, joined by pipes

    Runix Data and Runix Pipeline Layer 02 · Data

    Stages that each do one job and can be inspected between steps, with the rules for code, finance, cybersecurity, legal, embodied AI and science on top.

  3. a kernel that does the work

    Runix Models Layer 03 · Models

    Open-weight models tuned to your task and served on dedicated capacity: the part of the system that does the thinking, and one you can own.

  4. one call interface

    Runix Router Layer 04 · Gateway

    One OpenAI-compatible API in front of every model provider, with keys, limits and failover handled beneath it, the way system calls keep the hardware out of a program's way.

  5. userland

    Runix Code and Runix Comic Layer 05 · Applications

    Products built on the layers beneath them, which can change without touching the storage, data or models underneath.

01

Efficient

GPUs read from a cache instead of waiting on the bucket, requests are routed by cost and health, and a small tuned model takes the jobs a large general one does not need to do.

02

Stable

Failover between providers happens mid-request with streaming preserved, file-system metadata is replicated with Raft, and every data stage leaves something you can inspect.

03

Enterprise-grade

A US company to contract with, MSA and DPA on request, central key custody with per-key quotas, and deployment into your own cloud account where the data has to stay.

Layer 01

Infrastructure

The file system that keeps GPUs fed from the object storage you already run.

A POSIX file system and multi-tier cache over the object storage you already pay for, so training jobs, inference servers and agents stop waiting on the bucket.
